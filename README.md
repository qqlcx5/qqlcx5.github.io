## 🌐 站点简介

本项目为 **前端有道** 官方网站的 GitHub Pages 自动化托管部署仓库。网站由 VuePress 构建，旨在为广大开发者提供系统化、高质量的前端知识图谱与技术指南。

- 🚀 **主站入口**：[https://feyoudao.cn](https://feyoudao.cn)
- 📌 **备用入口**：[https://qqlcx5.github.io](https://qqlcx5.github.io)
- 💻 **源码仓库**：[qqlcx5/blog](https://github.com/qqlcx5/blog)

## 📚 知识板块

- **前端核心与进阶**：JavaScript 核心机制、TypeScript 类型体操、ESNext 前沿规范、Vue 2/3 源码剖析、React 实战。
- **工程化与架构**：Vite / Webpack / Rolldown 构建优化、前端性能调优、CI/CD 自动化交付流程、Monorepo 架构。
- **跨端与多端方案**：Uni-app 深度实战、微信小程序开发、Tauri / Electron 桌面应用。
- **AI 与智能体前沿**：Agent 架构设计、Prompt Engineering、MCP 协议集成、LLM 工作流沉淀。
- **算法与日常踩坑**：LeetCode 重点题解、线上故障定位与最佳解决方案。

## 🛠️ 技术实现

本站点基于现代前端静态网站生成体系驱动：
* **静态站点生成器**：VuePress 1.9
* **主题框架**：`vuepress-theme-vdoing`（优雅的知识库/博客主题）
* **搜索增强**：FullText 全文检索与 DocSearch
* **SEO 优化**：Sitemap 自动生成、百度/Google 搜索推送插件
* **托管服务**：GitHub Pages + 自定义域名 CDN 解析
